# RuangBimbing

Aplikasi web demo untuk monitoring bimbingan akademik Program Studi Informatika. Aplikasi menggunakan HTML, CSS, dan JavaScript tanpa proses build atau dependensi tambahan.

## Menjalankan aplikasi

Buka `index.html` di browser modern. Data demo disimpan di `localStorage` browser.

## Akun demo

Semua akun menggunakan kata sandi `demo123`.

| Peran | Email |
|---|---|
| Mahasiswa | `mahasiswa@kampus.ac.id` |
| Dosen | `dosen@kampus.ac.id` |
| Admin | `admin@kampus.ac.id` |

## Alur demo

- Mahasiswa dapat mengajukan bimbingan, memeriksa jadwal, dan membaca hasil konsultasi.
- Dosen dan admin dapat menjadwalkan permohonan, mencatat hasil bimbingan, melihat riwayat, serta mengunduh laporan CSV.
- Admin dan dosen dapat melihat aktivitas seluruh mahasiswa pada data demo; mahasiswa hanya melihat bimbingannya sendiri.

## Batasan keamanan

Ini adalah prototipe sisi-klien untuk demonstrasi. Akun dan kata sandi demo, otorisasi, serta data berada di browser dan bukan mekanisme autentikasi atau penyimpanan yang aman. Jangan gunakan data pribadi atau data akademik nyata. Penerapan produksi memerlukan backend, basis data, autentikasi dan otorisasi server, validasi input, serta kontrol privasi yang sesuai.
